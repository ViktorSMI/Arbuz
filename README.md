# 🍉 Arbuz Souls

**Arbuz Souls** — браузерная 3D action-RPG о последнем арбузе. Арбузилле предстоит пройти шесть земель, собрать камни памяти, победить шесть стражей и остановить Жан-Пьера Дюваля.

## Запуск игры

Node.js для игры не нужен.

1. Скачайте или распакуйте репозиторий целиком.
2. Откройте `index.html` обычным двойным кликом.
3. Нажмите «Начать путь» — откроется автономная сборка `index3d.html`.

`index3d.html` загружает готовый `js/game.bundle.js`. Интерфейс, Three.js и игровые модули уже собраны внутрь бандла: во время запуска нет `fetch`, import map и локального HTTP-сервера.

### Режимы

- `index3d.html` — Arbuz Souls, основная 3D-игра;
- `arcade.html` — World Conquest, классический 2D-режим;
- `projection-hall/index.html` — Projection Hall.

## Опциональный сервер

`server.js` не запускает игровую логику и не требуется одиночной игре. Он нужен только как статический сервер и WebSocket relay для сетевых экспериментов.

```bash
npm install
npm start
```

После запуска relay доступен по адресу `ws://localhost:3456/ws`. Клиентская игра при этом остаётся браузерной.

## Пересборка автономной версии

Готовый `js/game.bundle.js` хранится в репозитории, поэтому игрокам ничего собирать не нужно. После изменения исходников разработчик может обновить его командой:

```bash
npm install
npm run build
```

При изменениях в `main` GitHub Actions также пересобирает бандл автоматически.

## Мир

Путь Арбузиллы проходит через Зелёные холмы, Подземелья крыс, Вороньи скалы, Токсичную свалку, Военную базу и Кухню ада. В каждой земле находятся три камня памяти и один страж.

Камни памяти рассказывают о семенах жизни, падении фруктового народа, происхождении стражей и пророчестве о последнем арбузе. Жан-Пьер Дюваль охотится за семечкой Арбузиллы ради своего последнего рецепта.

## Основные файлы

```text
index.html                 — локальный стартовый экран
index3d.html               — автономная оболочка 3D-игры
arcade.html                — 2D-режим World Conquest
js/game.bundle.js          — готовая браузерная сборка
js/local-entry.js          — точка входа автономной сборки
js/main.js                 — основной игровой цикл
ui/                        — исходные фрагменты интерфейса
scripts/build-local.mjs    — сборка бандла
server.js                  — опциональный HTTP/WebSocket relay
```
