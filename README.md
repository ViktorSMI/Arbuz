# 🍉 Arbuz Souls

**Arbuz Souls** — браузерная 3D action-RPG о последнем арбузе. Арбузилле предстоит пройти шесть земель, собрать камни памяти, победить шесть стражей и остановить Жан-Пьера Дюваля.

## Режимы

- **`/game` — Arbuz Souls.** Основная 3D-игра.
- **`/arcade` — World Conquest.** Классический 2D-режим о захвате территорий.
- **`/projection-hall/` — Projection Hall.** Отдельный проекционный зал.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm start
```

После запуска:

- стартовый экран: `http://localhost:3456`
- игра: `http://localhost:3456/game`
- WebSocket relay: `ws://localhost:3456/ws`

Для разработки с автоматическим перезапуском сервера:

```bash
npm run dev
```

## Управление

| Действие | Управление |
|---|---|
| Движение | `WASD` |
| Бег | `R` |
| Прыжок | `Space` |
| Уворот | `Shift` |
| Атака | ЛКМ |
| Блок / парирование | ПКМ |
| Захват цели | СКМ или колесо |
| Взаимодействие | `E` |
| Инвентарь | `Tab` |
| Журнал | `J` |
| Пауза / настройки | `Esc` |
| Способности | `Q`, `F`, `C`, `1`–`4` |

На сенсорных экранах включается экранное управление.

## Мир

Путь Арбузиллы проходит через Зелёные холмы, Подземелья крыс, Вороньи скалы, Токсичную свалку, Военную базу и Кухню ада. В каждой земле находятся три камня памяти и один страж.

Камни памяти рассказывают о семенах жизни, падении фруктового народа, происхождении стражей и пророчестве о последнем арбузе. Жан-Пьер Дюваль охотится за семечкой Арбузиллы ради своего последнего рецепта.

## Системы

- бой, блок, парирование, уворот и захват цели;
- семь активных способностей;
- уровни, улучшения характеристик и экипировка;
- ветвящиеся диалоги, репутация, торговля и кража;
- спутники и задания NPC;
- восемнадцать камней памяти;
- контрольные точки, автосохранение и New Game+.

## Сохранение

Сохранение хранится в `localStorage` под ключом `arbuz_souls_save`.

В него входят характеристики игрока, экипировка, семечки, репутация, найденные камни памяти, текущая земля, состояние босса, спутники, задания, время прохождения и контрольная точка.
