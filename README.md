# 🍉 Arbuz Souls

**Arbuz Souls** — браузерная 3D action-RPG о последнем арбузе, который проходит шесть разрушенных земель и возвращает миру Семя Жизни.

Репозиторий теперь содержит не один прототип, а три явно разделённых режима:

- **`/game` — основная 3D-кампания.** Шесть актов, боссы, задания, развилки в диалогах, прокачка, экипировка, компаньоны, лор, контрольные точки, автосохранение и New Game+.
- **`/arcade` — оригинальная 2D-аркада.** Старый режим сохранён без потери функциональности.
- **`/projection-hall/` — экспериментальный проекционный зал.**

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm start
```

После запуска:

- стартовый экран: `http://localhost:3456`
- кампания: `http://localhost:3456/game`
- WebSocket relay: `ws://localhost:3456/ws`

Для разработки с автоматическим перезапуском сервера:

```bash
npm run dev
```

## Что делает кампанию законченной игрой

### Сюжетная структура

Кампания разделена на шесть актов. Каждый акт имеет собственный биом, главную цель, босса, три камня памяти и контрольную точку. Интерфейс всегда показывает текущую задачу и прогресс.

### Реальные игровые системы

- способности наносят урон через общую боевую систему;
- убийства способностями выдают XP, семечки и шанс на экипировку;
- урон по боссам запускает их фазы, контратаки, награды и кинематографическую смерть;
- броня, блок, парирование и «Живая корка» действительно уменьшают входящий урон;
- NPC используют ветвящиеся диалоги с проверками уровня, репутации и количества семечек;
- решения могут дать задание, изменить репутацию, открыть торговлю, кражу или спутника;
- журнал собирает главную цель, задания NPC, статистику и найденный лор.

### Сохранение

Сохранение версии 2 хранится в `localStorage` под ключом `arbuz_souls_save` и включает:

- характеристики, уровень, XP, семечки и экипировку;
- репутацию, найденный лор и New Game+;
- текущий акт, позицию, арену и состояние босса;
- активных компаньонов и задания NPC;
- время прохождения, число смертей, выборы в диалогах и контрольную точку.

Старые сохранения версии 1 автоматически мигрируют в новый формат.

## Архитектура

```text
index.html              — лаунчер режимов
index3d.html            — интерфейс 3D-кампании
arcade.html             — сохранённая оригинальная 2D-игра
css/game.css            — UI кампании
js/main.js              — основной игровой цикл
js/campaign.js          — кампанийный слой и интеграция систем
js/campaign-core.js     — чистая модель актов, целей и статистики
js/save.js              — сохранения v2 и миграция
js/skills.js            — способности и их боевые последствия
server.js               — статический HTTP-сервер + WebSocket relay
```

Кампания добавлена поверх существующего движка без создания второго независимого состояния игрока: интерфейс, задания, сохранения, бои и мир используют те же singleton-модули.

## Проверки

```bash
npm test
npm run check
```

Тесты проверяют модель кампании, миграцию сохранений, ключевые DOM-контракты и наличие основных интеграций.

## Сетевой relay

`server.js` отдаёт игру и поднимает WebSocket endpoint `/ws` на том же порту. Relay принимает только сообщения `state`, ограничивает размер пакета и нормализует позицию, HP, уровень и имя игрока. Он предназначен как база для дальнейшего кооператива; основная кампания полностью работает в одиночном режиме.
